# Mac crash logs — M3 Max

这里收集了这台 M3 Max Mac 的崩溃日志和相关资料，希望有经验的朋友协助查看，并推荐国内可靠的维修店或维修师傅。

## 设备情况

- 机器有过进水，目前有 3 个按键失灵。
- 据机主反馈，苹果技术团队已经确认主板存在问题，给出的方案是更换主板。
- 据机主获得的报价，更换费用约人民币一万多元，维修后仅质保三个月。机主认为成本过高，希望了解是否有可靠的板级维修方案。
- 进水、键盘故障与主板问题之间的具体关系尚未确定。

## 日志说明

日志文件日期覆盖 2025 年 5 月至 2026 年 3 月，保留原有目录与文件名；同一崩溃的重复摘要已删除，保留完整报告。

- 根目录：较新的 `.panic` 文件。
- `Crash/`：较早的 panic 日志、系统日志摘录、截图及历史 AI 分析。
- 多份日志的 panic 信息包含 `LLC Bus error`，2025-11-06 的日志包含 `Mutex interlock ... timeout`。这些是日志中的文字，不代表已经定位到具体损坏元件。
- 建议先查看最新的 [`panic-full-2026-03-29-212320.0002.panic`](panic-full-2026-03-29-212320.0002.panic)，再结合其他日期的日志比较。

`Crash/chatgpt-analyzed-result-2025-11-06.txt` 是当时生成的 AI 分析，未经独立验证，其中对 SSD 故障的确定性判断与概率数字不应当作诊断结论，也不代表苹果技术团队的意见。
